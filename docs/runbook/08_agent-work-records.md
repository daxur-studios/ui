# Agent Work Records — Runbook

## 2026-10-22

- **[decision]** Treat a coherent repository-work request as the tracking unit; reuse an initiative pair, create a pair for substantial new work, and route small standalone work or investigations to a monthly work log — one durable record link per task avoids both untracked work and one-document-per-session growth.
- **[decision]** Do not require provider-specific session IDs or ask whether a plan/runbook is wanted; ask only for missing information that materially changes scope, and otherwise record assumptions or open questions and proceed.
- **[action]** Added the routing and handback rules to `AGENTS.md` and `docs/plans-and-runbooks.md`, plus the work-log guide and index under `docs/work-log/`; left monthly files absent until the first standalone task needs one.
- **[finding]** The policy and reciprocal links are documented without a CLI change; the policy work itself uses this initiative pair, so no empty monthly work-log file was created.
